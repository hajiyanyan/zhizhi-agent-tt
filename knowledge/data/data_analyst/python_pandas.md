# Pandas 缺失值处理
## 核心概念
Pandas 使用 NaN 表示浮点型缺失值，NaT 表示时间缺失。缺失值会影响统计、模型训练，需要根据业务选择策略。

## 关键区别
- dropna()：直接删除含缺失的行/列，适合缺失极少、样本量大场景。
- fillna()：填充缺失值，均值、中位数、前向填充ffill、后向填充bfill、固定值填充。
- interpolate()：插值填充，适合时序连续数据。

## 常见错误
不分业务场景无脑均值填充时序缺失；忽略缺失本身具备业务含义（缺失本身是信息）。
