# 时间复杂度与空间复杂度
## 核心概念
时间复杂度用来衡量算法运行时间随输入规模增长的变化趋势；空间复杂度衡量算法额外占用内存空间随输入规模增长的趋势。
我们一般讨论最坏时间复杂度，渐进上界，使用大O记号表示。

## 关键区别
- 时间复杂度：关注执行步骤数量，不统计精确运行毫秒，只看增长阶。
- 空间复杂度：关注除输入本身之外，额外开辟的辅助空间。递归算法栈帧需要计入空间复杂度。

## 常见面试问题
1. 什么是大O表示法？为什么不用精确运行时间衡量算法效率？
2. 递归算法的空间复杂度怎么计算？
3. O(nlogn) 和 O(n²) 在大数据量下差异体现在哪里？

## 常见错误
1. 把循环次数直接等同于时间复杂度，忽略嵌套循环、递归分支。
2. 忘记递归调用栈带来的额外空间开销。
3. 将最好情况复杂度当作算法复杂度。
